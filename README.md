# 엑셀 이미지 삽입 프로그램

엑셀 파일과 이미지 폴더를 입력받아, 엑셀 셀 값과 동일한 이름을 가진 이미지를 자동으로 찾아서 지정한 셀 위치부터 가로 방향으로 삽입하는 GUI 프로그램입니다.

## 🎯 주요 기능

- **GUI 기반 사용**: 비개발자도 쉽게 사용할 수 있는 직관적인 인터페이스
- **정확한 이미지 매칭**: 구분자 기반 매칭으로 "1"과 "10"을 명확히 구분
- **이미지 크기 조정**: 셀 크기에 자동 맞춤 또는 수동 크기 설정 지원
- **수식 지원**: 엑셀 수식(예: `=A5+1`)의 계산된 결과값을 기준으로 매칭
- **가로 방향 삽입**: 여러 이미지가 매칭되면 가로 방향으로 순차 삽입
- **일관된 크기 유지**: 한 행에 여러 이미지 삽입 시 모두 동일한 크기로 삽입
- **실시간 로그**: 작업 진행 상황을 실시간으로 확인
- **크로스 플랫폼**: Windows / Mac 모두 실행 가능

## 📋 요구사항

- Python 3.8 이상
- 다음 Python 패키지:
  - `openpyxl>=3.1.2`
  - `Pillow>=10.0.0`

## 🚀 설치 및 실행

### 방법 1: Python으로 직접 실행 (개발 환경)

1. **프로젝트 디렉토리로 이동**
   ```bash
   cd /path/to/excel-image-inserter
   ```

2. **필요한 패키지 설치**
   ```bash
   pip install -r requirements.txt
   ```

3. **프로그램 실행**
   ```bash
   python main.py
   ```

### 방법 2: 실행 파일로 실행 (배포 환경)

#### Windows

1. **PyInstaller 설치** (한 번만)
   ```bash
   pip install pyinstaller
   ```

2. **실행 파일 생성**
   ```bash
   pyinstaller --onefile --windowed --name excel_image_inserter main.py
   ```

3. **생성된 실행 파일 실행**
   - `dist/excel_image_inserter.exe` 파일을 더블클릭하여 실행

#### Mac

1. **PyInstaller 설치** (한 번만)
   ```bash
   pip install pyinstaller
   ```

2. **실행 파일 생성**
   ```bash
   pyinstaller --onefile --windowed --name excel_image_inserter main.py
   ```

3. **생성된 앱 실행**
   - `dist/excel_image_inserter.app` 파일을 더블클릭하여 실행

## 📦 배포 파일 목록

배포를 위해 다음 파일들이 필요합니다:

### 필수 파일
- `main.py` - 메인 진입점
- `requirements.txt` - 의존성 패키지 목록
- `model/` - Model 계층 (엑셀 처리, 이미지 매칭 로직)
- `view/` - View 계층 (GUI)
- `presenter/` - Presenter 계층 (View-Model 연결)

- **Windows**: `excel_image_inserter.exe`
- **Mac**: `excel_image_inserter.app`

## 📖 사용 방법

1. **엑셀 파일 선택**
   - "찾아보기" 버튼을 클릭하여 엑셀 파일(.xlsx, .xlsm)을 선택합니다.

2. **이미지 폴더 선택**
   - "찾아보기" 버튼을 클릭하여 이미지가 들어있는 폴더를 선택합니다.

3. **시트 선택**
   - 엑셀 파일을 선택하면 자동으로 시트 목록이 로드됩니다.
   - 드롭다운에서 사용할 시트를 선택합니다.

4. **매칭 기준 열 입력**
   - 이미지와 매칭할 기준이 되는 열을 입력합니다. (예: A, B, C)

5. **삽입 시작 셀 입력**
   - 이미지를 삽입할 시작 셀을 입력합니다. (예: C5, D10)

6. **이미지 크기 설정**
   - **셀 크기에 맞춤**: 이미지를 자동으로 셀 크기에 맞춰 조정합니다.
   - **수동 설정**: 원하는 너비와 높이(픽셀)를 직접 입력합니다.
     - 너비만 입력: 비율을 유지하며 너비에 맞춤
     - 높이만 입력: 비율을 유지하며 높이에 맞춤
     - 둘 다 입력: 지정한 크기로 정확히 조정

7. **실행**
   - "실행" 버튼을 클릭하여 작업을 시작합니다.

8. **결과 확인**
   - 로그 창에서 작업 진행 상황을 확인할 수 있습니다.
   - 작업이 완료되면 엑셀 파일이 자동으로 저장됩니다.

## 🔍 동작 원리

### 데이터 조회 규칙

- 매칭 기준 열(A열 등)을 위에서 아래로 순회합니다.
- 셀이 비어 있으면 그 행에서 즉시 종료합니다.

예:
```
A열
1
2
3
(빈칸) ← 여기서 중단
```

### 이미지 매칭 규칙

#### 정확한 매칭 (구분자 기반)

셀 값이 `X`일 때, 다음과 같은 파일명 패턴을 매칭합니다:

**✅ 매칭되는 패턴:**
- `X.확장자` - 정확히 일치 (예: `1.png`, `2.jpg`)
- `X-추가정보.확장자` - 하이픈 구분자 (예: `1-a.png`, `1-front.jpg`)
- `X_추가정보.확장자` - 언더스코어 구분자 (예: `1_001.png`, `2_back.jpg`)
- `X 추가정보.확장자` - 공백 구분자 (예: `1 image.png`)
- `X(추가정보).확장자` - 괄호 구분자 (예: `1(1).png`, `2(2).jpg`)

**❌ 매칭되지 않는 패턴:**
- `XY.확장자` - 숫자가 바로 이어지는 경우 (예: 셀 값 "1"일 때 `10.png`, `11.png`는 매칭 안 됨)

#### 매칭 예시

| 셀 값 | 매칭되는 이미지 | 매칭되지 않는 이미지 |
|-------|----------------|---------------------|
| `1` | `1.png`, `1-a.png`, `1_001.png`, `1 (1).png` | `10.png`, `11.png`, `12.png` |
| `2` | `2.jpg`, `2-front.jpg`, `2_back.png` | `20.png`, `21.jpg` |
| `A12` | `A12.png`, `A12-1.jpg`, `A12_001.png` | `A120.png`, `A121.jpg` |

#### 수식 지원

엑셀 수식이 포함된 셀의 경우, **계산된 결과값**을 기준으로 매칭합니다.

예시:
- A4 = `1`
- A5 = `=A4+1` (표시값: `2`)
- A6 = `=A5+1` (표시값: `3`)

결과:
- A5 행 → 값 `2`로 인식 → `2.png`, `2-a.png` 등 매칭
- A6 행 → 값 `3`으로 인식 → `3.png`, `3-a.png` 등 매칭

> **⚠️ 주의**: 수식의 계산된 값은 엑셀 파일이 저장된 시점의 값입니다. 수식을 추가한 후 반드시 파일을 저장해주세요.

### 이미지 삽입 규칙

#### 기본 삽입 규칙

매칭된 이미지가 여러 개일 경우:
- 첫 번째 이미지는 시작 셀에 삽입 (예: C5)
- 두 번째부터는 오른쪽 셀에 순서대로 삽입 (D5, E5, ...)

예:
- 매칭 기준 셀: A5 = `1`
- 삽입 시작 셀: C5
- 매칭 이미지: `1.png`, `1-a.png`, `1-b.png`

결과:
```
A5    C5        D5        E5
1     1.png     1-a.png   1-b.png
```

#### 이미지 크기 조정

**1. 셀 크기에 맞춤 모드**
- 첫 번째 이미지가 삽입될 셀의 크기를 자동으로 계산
- 해당 행의 모든 이미지를 동일한 크기로 조정하여 삽입
- 한 행에 여러 이미지가 있어도 일관된 크기 유지

예시:
```
C5 셀 크기: 100px × 50px
→ C5, D5, E5에 삽입되는 모든 이미지 = 100px × 50px
```

**2. 수동 설정 모드**
- 사용자가 지정한 너비/높이로 이미지 크기 조정
- **너비만 지정**: 비율을 유지하며 너비에 맞춤
- **높이만 지정**: 비율을 유지하며 높이에 맞춤  
- **둘 다 지정**: 정확히 지정한 크기로 조정 (비율 무시)

예시:
```
원본 이미지: 800px × 600px (비율 4:3)
- 너비 200px만 지정 → 200px × 150px (비율 유지)
- 높이 100px만 지정 → 133px × 100px (비율 유지)
- 너비 200px, 높이 100px → 200px × 100px (정확한 크기)
```

## 📜 로그 시스템

프로그램 실행 중 다음 로그 타입이 출력됩니다:

| 종류 | 예 |
|------|-----|
| SUCCESS | A5 → 1.png 삽입 완료 |
| FAIL | A6 → 이미지 없음 |
| ERROR | 이미지 로드 실패 |
| SUMMARY | 총 30행 중 27개 성공 |

### 에러 코드

- **E001**: 엑셀 로드 실패
- **E002**: 이미지 폴더 없음
- **E003**: 셀 좌표 오류
- **E004**: 이미지 삽입 실패

## 🏗️ 아키텍처

이 프로그램은 **MVP (Model-View-Presenter)** 패턴으로 설계되었습니다:

- **Model**: 엑셀 처리, 이미지 매칭, 삽입 로직
- **View**: tkinter GUI
- **Presenter**: View와 Model 연결, 입력 검증, 예외 처리

이 구조로 인해:
- 나중에 기능 추가 (PDF, 다른 포맷, 열 방향 변경 등)가 쉬워집니다.
- GUI 교체 (tkinter → web)가 용이합니다.

## 🐛 문제 해결

### "엑셀 파일을 로드할 수 없습니다" 오류
- 엑셀 파일이 다른 프로그램에서 열려있는지 확인하세요.
- 파일 경로에 특수문자가 없는지 확인하세요.

### "이미지 폴더가 존재하지 않습니다" 오류
- 이미지 폴더 경로가 올바른지 확인하세요.
- 폴더 접근 권한을 확인하세요.

### "시트를 선택할 수 없습니다" 오류
- 엑셀 파일에 시트가 있는지 확인하세요.
- 시트 이름이 올바른지 확인하세요.

### 이미지가 매칭되지 않을 때
- 파일명이 셀 값과 정확히 일치하는지 확인하세요.
- 구분자(`-`, `_`, ` `, `(`, `.`)를 사용했는지 확인하세요.
- 예: 셀 값 "1"일 때 → `1.png` ✅, `10.png` ❌

### 수식 값이 인식되지 않을 때
- 엑셀 파일을 열어서 수식이 정상적으로 계산되는지 확인하세요.
- 파일을 저장한 후 다시 프로그램을 실행하세요.
- 수식이 한 번도 계산되지 않은 경우 `None`으로 인식될 수 있습니다.

### 이미지 크기가 이상할 때
- **셀 크기에 맞춤** 모드: 엑셀의 셀 크기를 확인하세요.
- **수동 설정** 모드: 입력한 너비/높이 값이 올바른지 확인하세요.
- 한 행에 여러 이미지 삽입 시: 모두 동일한 크기로 조정되는 것이 정상입니다.

### 실행 파일이 실행되지 않을 때
- Python이 설치되어 있는지 확인하세요.
- 필요한 패키지가 모두 설치되어 있는지 확인하세요.
- 터미널에서 오류 메시지를 확인하세요.
